# What is TYLA Media Player
- TYLA media player is a multimedia player application built using Java in order to learn more about how media players work and how they could be improved.
- For audiophiles, audio engineers, and artists creating unreleased music, there is still a need for a versatile media player that plays all kinds of audio files.
- For those who have large collections of films and video files, they too need a media player that can play all their files.

## What is it for?
- This project was created for the Software Engineering and Practice course at Oakland University.
- It was developed by Ayah Alshami, Luc Chapman, Yuepeng Xiong, and Tyler Conway over the course of the semester.

## How to use
- Right now you can run the TYLAApplication file from your IDE in order to test out the media player.
- Then you can link directories containing music and video files and even multiple sub-directories to the program for it to scan.
- The program will gather, populate, and sort all of the relevant files in those directories into its UI including any metadata per file.
- You can then play music or video however you please through the media player

## Future Plans
Potential updates for the media player include:
- CPU and GPU optimizations
- updated UI
- customizable scrubbing features
- metadata editing from the media player
- and more...
